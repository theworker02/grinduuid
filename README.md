# grinduuid

Grind and reshape uuid text streams with deterministic transforms.

**Site:** https://theworker02.github.io/grinduuid/

## Install / run

```bash
git clone https://github.com/theworker02/grinduuid.git
cd grinduuid
node src/cli.js
node --test
```
